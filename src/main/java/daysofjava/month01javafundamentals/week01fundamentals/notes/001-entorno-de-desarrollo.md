# **Preparar tu entorno de desarrollo Java**

Hoy no vamos a complicarnos con algoritmos. El objetivo es volver a tener un entorno preparado y escribir tus primeras líneas de código.

## **1. Objetivo de aprendizaje**

- Comprobar que tienes Java correctamente instalado.
- Familiarizarte de nuevo con IntelliJ IDEA.
- Recuperar el flujo de trabajo de programación.
- Crear tu repositorio de GitHub.
- Compilar y ejecutar tu primer programa Java.

## **2. Retos del día**

**Reto 1 — Preparar el entorno**

- Comprobar la instalación del JDK.
- Comprobar la configuración de IntelliJ IDEA.
- Comprobar que Git funciona.
- Verificar las versiones instaladas desde la terminal.

**Reto 2 — Crear el repositorio**

Crea un repositorio público en GitHub llamado:

`365-days-of-java`

Configúralo con:

- README.md
- .gitignore para Java
- Una descripción del objetivo del reto.

**Reto 3 — Tu primer programa**

Crea un proyecto Java y escribe una clase llamada `Main`.

Requisitos:

- Debe contener el método `main`.
- Debe imprimir un mensaje de bienvenida al reto.
- Debe imprimir el número de día y el objetivo del proyecto.
- Debe ejecutarse correctamente.

**Reto 4 — Ejecutar desde dos sitios**

- Ejecutar el programa desde IntelliJ IDEA.
- Compilar y ejecutar el programa desde la terminal.
- Comprobar que ambas ejecuciones producen el resultado esperado.

## **3. Criterios de aceptación**

No des el día por terminado hasta cumplir todo esto:

- JDK instalado y operativo.
- Git configurado.
- Repositorio creado en GitHub.
- Proyecto Java creado.
- Clase `Main` funcionando.
- Ejecución correcta desde IDE y terminal.
- README actualizado.
- Cambios subidos a GitHub.

## **4. Preguntas de comprobación**

Antes de terminar, asegúrate de poder responder:

1. ¿Qué diferencia existe entre JDK y JVM?
2. ¿Para qué sirve el método `main`?
3. ¿Qué ocurre cuando compilas un archivo `.java`?
4. ¿Qué diferencia hay entre ejecutar un programa desde IntelliJ y hacerlo desde la terminal?

No necesitas memorizar las respuestas: necesitas entenderlas.

## **5. Commit del día**

Cuando hayas terminado, utiliza un mensaje como:

```
git add .
git commit -m "day-001: initialize Java environment"
git push
```
