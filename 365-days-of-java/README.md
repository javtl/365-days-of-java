## 📖 Sobre el reto

**365 Days of Java** es un reto personal de programación cuyo objetivo es mejorar progresivamente mis conocimientos de Java, fortalecer mi lógica de programación y adquirir habilidades propias de un desarrollador backend.

Durante 365 días trabajaré en ejercicios, pequeños proyectos y aplicaciones cada vez más complejas, siguiendo una ruta de aprendizaje estructurada.

Este reto también busca desarrollar hábitos de trabajo profesionales: escribir código limpio, realizar pruebas, utilizar Git correctamente y documentar el proceso de aprendizaje.

## 🎯 Objetivos

- Recuperar y consolidar los fundamentos de Java.
- Mejorar la lógica de programación y la resolución de problemas.
- Dominar la programación orientada a objetos.
- Aprender estructuras de datos y algoritmos.
- Trabajar con bases de datos y SQL.
- Aprender herramientas del ecosistema Java.
- Aplicar buenas prácticas, testing y principios SOLID.
- Desarrollar aplicaciones backend con Spring Boot.
- Construir proyectos que puedan formar parte de mi portfolio.

## 📅 Reglas del reto

1. Dedicar tiempo a programar y aprender cada día.
2. Priorizar la comprensión frente a la cantidad de código.
3. Documentar los aprendizajes y dificultades.
4. Realizar commits descriptivos y frecuentes.
5. Revisar y refactorizar código anterior.
6. Aumentar progresivamente la dificultad.
7. No avanzar sin comprender los conceptos fundamentales.
